## 🚨 트러블슈팅: `[Errno 2] No such file or directory`

### - 학습한 내용
Python 실행 시 `[Errno 2] No such file or directory` 오류가 발생했다. 원인을 확인해 보니 실행할 Python 파일의 **확장자(.py)를 입력하지 않아** 파일을 찾지 못한 것이었다. 이를 통해 에러 메시지를 먼저 확인하고 파일명과 실행 명령어를 정확하게 입력하는 것이 중요하다는 점을 배웠다.

### - 어려웠던 부분
처음에는 경로나 디렉터리 문제라고 생각해 폴더 구조를 확인했지만, 실제 원인은 실행 명령어에서 `.py` 확장자를 생략한 단순한 실수였다.

### - 새로 배운 점 및 느낀 점
`[Errno 2]`는 파일이나 디렉터리를 찾을 수 없을 때 발생하는 오류이며, 코드뿐 아니라 **파일명, 확장자, 실행 경로**도 함께 확인해야 한다는 것을 알게 되었다. 앞으로는 오류가 발생하면 기본적인 실행 환경부터 차례대로 점검하는 습관을 가지려고 한다.
