## 🚨 Trouble Shooting

### 1. `[Errno 2] No such file or directory`

#### - 학습한 내용
Python 실행 시 `[Errno 2] No such file or directory` 오류가 발생했다. 원인을 확인해 보니 실행할 Python 파일의 **확장자(.py)를 입력하지 않아** 파일을 찾지 못한 것이었다. 이를 통해 에러 메시지를 먼저 확인하고 파일명과 실행 명령어를 정확하게 입력하는 것이 중요하다는 점을 배웠다.

#### - 어려웠던 부분
처음에는 경로나 디렉터리 문제라고 생각해 폴더 구조를 확인했지만, 실제 원인은 실행 명령어에서 `.py` 확장자를 생략한 단순한 실수였다.

#### - 새로 배운 점 및 느낀 점
`[Errno 2]`는 파일이나 디렉터리를 찾을 수 없을 때 발생하는 오류이며, 코드뿐 아니라 **파일명, 확장자, 실행 경로**도 함께 확인해야 한다는 것을 알게 되었다. 앞으로는 오류가 발생하면 기본적인 실행 환경부터 차례대로 점검하는 습관을 가지려고 한다.

### 2. `defaultdict(int)`와 `{}`의 차이

#### - 학습한 내용
`defaultdict(int)`와 일반 딕셔너리(`{}`)의 차이를 이해하지 못해 원인을 찾아보았다. `defaultdict(int)`는 `dict`를 상속한 자료형으로, 일반 딕셔너리처럼 사용할 수 있지만 **존재하지 않는 키에 접근하면 기본값(0)을 자동으로 생성**하는 기능이 추가되어 있다는 것을 알게 되었다.

#### - 어려웠던 부분
일반 딕셔너리(`{}`)를 사용하는 코드에서도 `defaultdict(int)`가 정상적으로 동작하는 이유를 이해하기 어려웠다. 두 자료형이 완전히 다른 것으로 생각했지만, `defaultdict`가 `dict`를 상속받은 자료형이라는 점을 이해하면서 의문을 해결할 수 있었다.

#### - 새로 배운 점 및 느낀 점
`defaultdict(int)`는 일반 딕셔너리의 기능을 그대로 사용할 수 있으면서도 기본값을 자동으로 생성하는 기능이 추가된 자료형이다. 따라서 대부분의 `dict`를 사용하는 상황에서도 문제없이 사용할 수 있으며, 빈도 계산과 같이 키가 존재하는지 반복해서 확인해야 하는 작업에서 코드를 더욱 간결하게 작성할 수 있다는 점을 배웠다.

### 3. `pathlib`와 `json`을 활용한 카테고리별 통계 집계

#### - 학습한 내용
`pathlib.Path`로 파일 경로를 다루고 `.exists()`로 파일 존재 여부를 확인하는 방법을 학습했다. 또한 `json.load()`로 JSON 파일을 읽어 파이썬 객체(리스트/딕셔너리)로 변환하고, 딕셔너리를 활용해 카테고리별로 개수와 가격 합계를 누적 집계하는 방법을 익혔다.

#### - 어려웠던 부분
카테고리가 처음 등장할 때 딕셔너리에 키가 없어 발생하는 에러를 막기 위해 `if category not in category_stats`로 초기값을 먼저 세팅해주는 로직을 구성하는 부분이 헷갈렸다. 또한 평균 가격을 구할 때 합계(`price`)와 개수(`count`)를 분리 저장했다가 출력 시점에 나눠야 한다는 점을 떠올리는 데 시간이 걸렸다.

#### - 새로 배운 점 및 느낀 점
JSON 데이터를 읽으면 리스트 안에 딕셔너리가 담긴 구조로 그대로 다뤄진다는 것을 체감했고, 별도의 파싱 과정 없이 곧바로 반복문과 키 접근만으로 데이터를 다룰 수 있다는 점이 편리하게 느껴졌다. 단순 반복문처럼 보여도 딕셔너리를 누적기(accumulator)로 활용하면 통계 집계를 간결하게 구현할 수 있다는 점이 인상 깊었다.
